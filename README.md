# API Connect - [Carlos Henrique]

## Objetivo da API
Esta API foi desenvolvida para gerenciar o cadastro e a consulta de usuários, servindo como uma solução backend RESTful para fins de estudo e integração com clientes HTTP. O sistema opera com armazenamento em memória, garantindo agilidade na execução de rotas para criação, listagem e busca individual de registros.

## Tecnologias Utilizadas
* **Node.js** - Ambiente de execução JavaScript no servidor
* **Express** - Framework web para construção e roteamento da API
* **Git & GitHub** - Controle de versão e hospedagem do código-fonte
